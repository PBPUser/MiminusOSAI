Как это выглядит

Как обновиться

Новую версию объявляет один текстовый файл в репозитории. Чтобы выпустить обновление, пересобирать систему не нужно — достаточно изменить пять строк.

  1. Проверка. Центр обновления читает latest.txt и сравнивает объявленную версию с установленной.

  2. Загрузка. Пакет скачивается потоком и хешируется по дороге, так что файл читается один раз.

  3. Сверка суммы. Пакет без опубликованной SHA-256 или с несовпавшей суммой отклоняется до распаковки.

  4. Распаковка. Сборка раскладывается в update/ рядом с исполняемым файлом.

  5. Перезапуск. Система завершает работу, сценарий дожидается выхода процесса, копирует файлы поверх установки и запускает её снова.

# latest.txt — весь механизм выпуска
version  = 7.2
name     = МИМИНУС ОС 7.2
released = 2026-09-07
package  = …/dist/MiminusOS-7.2.zip
sha256   = 089DAB527635E44C…
